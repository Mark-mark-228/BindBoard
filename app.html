About
BindBoard
Version 1.0.0
Per-app macro keyboard for Windows
What it does
Second keyboard
Uses a separate USB keyboard as a dedicated macro pad — your main keyboard works as normal
Modes
Switch between profiles on the fly — one key to go from music controls to game macros
Action types
Open URLs, launch programs, play Soundpad sounds, switch modes — all from a key press
Key suppression
Intercepted keys don't reach other apps — press ESC on the macro pad without closing anything
App filter
Allow or block bindings based on which app is in focus
System tray
Closes to tray, not to exit — listener keeps running in the background
